# Invalidate cropped thumbnail cache

- Date: 2026-08-07 13:36:48 +07:00 (Asia/Bangkok)

## Request and intent

- Correct portrait image thumbnails that still appeared cropped in Grid view even though the browser CSS used `object-fit: contain`.
- Use the user's original portrait screenshot and its cropped Gallery thumbnail screenshot as the defect evidence.

## Cause

- Current ImageSharp generation already used `ResizeMode.Max`, but the server cache identity did not contain an algorithm version.
- WebPs generated by the earlier crop behavior therefore retained the same cache key and continued to bypass regeneration.
- The browser thumbnail URL also lacked a version, so a browser could retain an old cropped response even after server-side invalidation.

## Durable concepts established

- Full-ratio thumbnails are an end-to-end contract: ImageSharp uses `ResizeMode.Max`, regular Grid/List CSS uses `object-fit: contain`, and neither stage may discard source-image content.
- A single explicit thumbnail-algorithm version must participate in both the server cache identity and browser request URL.
- Increment that version when resize, orientation, or encoding semantics change instead of destructively clearing the shared cache.
