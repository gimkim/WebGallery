# Ignore Thumbs.db metadata files

- Date: 2026-08-07 16:41:19 +07:00 (Asia/Bangkok)

## Request and intent

- Make the Gallery system ignore Windows Explorer `Thumbs.db` files.

## Implementation

- Added one case-insensitive ignored-file-name rule in `FileSystemService` for `Thumbs.db`.
- Gallery directory enumeration now omits matching files while preserving a directory that happens to have that name.
- Recursive streamed folder ZIP enumeration skips matching files at every depth.
- File endpoints reject matching paths before resolving or serving them, covering direct Download, ViewFile/thumbnail, and Download selected requests in private and shared modes.

## Durable rule established

- `Thumbs.db` is Windows metadata, not gallery content. It must remain absent from listings and ZIPs and inaccessible through file-serving endpoints regardless of filename casing.
