# Automatic earlier ranges and per-user folder sorting

- Request: automatically load earlier items when scrolling upward after a jump; remember each user's last sort independently for each folder.
- Implementation: upper/lower sentinels trigger one bounded request at a time; earlier button hidden unless retry needed. Prepend compensates using the existing first card rather than display:contents chunk wrapper; grid opts out of native scroll anchoring to prevent double compensation. Short jump windows may immediately fetch an earlier range when its sentinel is visible.
- Sort persistence: additive SQLite FolderBrowsePreferences table, owner/key composite primary key and cascading account FK; normalized logical folder keys hashed, Windows case-insensitive/Linux case-sensitive. Index resolves saved sort/direction (default name/asc); explicit query overrides and atomic upsert only on change. Private folder/back/breadcrumb hrefs no longer propagate source-folder sort. Chunk requests explicitly preserve listing sort without overwriting saved preference. Shared presentations unchanged.
