# SPA navigation with original URLs

- Date: 2026-09-08, Asia/Bangkok.
- Request: Convert the website to API-driven single-page navigation while preserving changing URLs, real links and middle-click/new tabs.
- Server: PageApiFilter content-negotiates ViewResults using X-Gallery-Page:1 and application/vnd.webgallery.page+json. Existing MVC actions render JSON-wrapped page HTML under the same authorization/antiforgery/share/audit logic. API output is no-store, has a known content length and Vary header. Ordinary direct links still return HTML. Returned page scripts are removed and never evaluated client-side.
- Client: spa-router.js streams the page API response, displays real HTTP status/decoded received bytes, trustworthy progress when unencoded length is available, and elapsed time. DOM replacement is limited to navigation/main regions; document persists. Same-tab links and non-download forms use fetch; middle/modified/new-tab clicks and file downloads remain native. pushState/popstate preserve route URLs and saved entry scroll; existing parent-focus behavior continues. Requests are cancelable and late results cannot overwrite the current page. Uncertain POSTs are never automatically retried. Confirmation handlers execute before window-level submit interception.
- Lifecycle: page-scope.js scopes global listeners, observers, timers and fetch to each mount of site.js/video-player.js. Unmount runs existing pagehide cleanup, closes media, aborts fetch, removes handlers and disconnects observers before installing the next page. Legacy native loading/console scripts remain on disk but are no longer included in the layout.
