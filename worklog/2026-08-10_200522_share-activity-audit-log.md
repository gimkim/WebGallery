# Share activity audit log with real IP addresses

- Date/time: 2026-08-10 20:05:22 Asia/Bangkok (UTC+07:00)
- User request: Record when and how often each share link is accessed, what recipients view and download, the time of each event, and the real client IP address.
- Concepts/rules established: Successful share page renders/navigation log Access events. Opening any image in the full viewer logs View through a dedicated validated POST so page-memory/browser-cache hits still count; `ViewFile`, thumbnails, cache probes, and background thumbnail work do not count. Direct file, folder ZIP, collection ZIP, and selected-file downloads log separate event types with normalized targets, item counts, and bounded valid JSON details. Each row stores UTC time, the direct `RemoteIpAddress`, and a stable per-link visitor hash derived from the share token plus that IP. Arbitrary forwarded headers remain untrusted. Logs remain until explicitly cleared or the share link is deleted.
- Data/UI: Added the SQLite `ShareAuditEvents` table and indexes with idempotent startup creation plus a `ClientIp` upgrade path. Folder and collection share management rows show Access/View/Download/unique-visitor totals and last activity. The owner-only Activity page shows newest-first events, actual IP, visitor identifier, target/details, pagination at 100 rows, aggregate cards, and an explicit confirmed clear action.
